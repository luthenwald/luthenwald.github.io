(Current) Projects

Slyz

Slyz is a GPU-accelerated programming language I am developing in Racket. It targets Apple Silicon via Metal and is organized around a categorical intermediate representation (CIR) that makes data-parallel structure explicit and amenable to formal reasoning. The design draws on applicative programming, Naperian-functor-based array combinators, and an algebraic effect system for managing memory and execution context.

The central ambition is a language in which high-level, shape-safe array programs can be written without the programmer reasoning about thread layout, memory coalescing, or warp divergence — and where correctness of the compilation to Metal shaders can be argued structurally.
